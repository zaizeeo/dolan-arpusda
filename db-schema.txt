// Catatan tipe dan relasi:
// - Kolom id pada tabel domain memakai string/varchar karena UUID dibuat
//   aplikasi melalui trait HasUuids.
// - foreignUuid di MySQL menjadi char(36). Beberapa kolom foreignUuid mengarah
//   ke id varchar; migration tidak membuat foreign key constraint untuk kolom
//   tersebut. Relasi tetap digambarkan sebagai Ref logis.
// - Tabel infrastruktur Laravel yang dikecualikan dari diagram: cache,
//   cache_locks, jobs, job_batches, failed_jobs, sessions, dan
//   password_reset_tokens.
// - deleted_at menandakan soft delete.
// - Semua timestamp dari timestamps() bersifat nullable.
// - Tabel migrations dibuat otomatis oleh Laravel dan tidak didefinisikan di
//   file migration, sehingga tidak disertakan dalam diagram ini.
// ============================================================================
